# Homestead

Homestead protects land in Minecraft Bedrock 1.26 or newer. Players use native
menus to create named rectangular or custom-shaped areas, then decide who may
enter, build, break, open containers and use blocks inside them.

!!! important "A rectangle uses only two points"

    Mark the first corner, then mark the diagonally opposite corner. Stop there:
    Homestead calculates the other two corners and creates all four sides
    automatically. A third point changes the selection to a custom boundary.

```text
1 +-------------------+
  |                   |
  |   protected area  |
  |                   |
  +-------------------+ 2
```

## Quick start

1. [Install both packs](installation.md) and activate them on the world.
2. Use the **Homestead Deed** and select **Mark an area**.
3. Mark two diagonally opposite corners with the Marking Wand.
4. Aim at empty space, use the wand and confirm the claim.
5. Give the area a name and configure its people, permissions and creatures.

No commands, cheats or experimental APIs are required. Operators can change
the world-wide claim count and block budget from the Administration menu.
